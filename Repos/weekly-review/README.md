# 周报可视化编辑器

一个轻量、好看、可本地直接运行的 **项目周报生成工具**。它把传统 Word/PPT 式周报变成一张可编辑、可切换风格、可导出图片 / PDF / Word 的精美报告页面。

无需后端、无需安装依赖，打开 `index.html` 即可使用。

---

## ✨ 项目亮点

- 🎨 **多套视觉主题**：有机苔原绿、深邃普鲁士、新中式雅致、硅谷活力橘、极智克莱因，适配不同汇报场景。
- 🧱 **模块化编辑**：支持标题、正文、列表、提示框、表格和高级组件，自由组合周报结构。
- 📊 **高级可视化组件**：内置项目甘特图、项目进度看板、日程看板，让进度和计划更直观。
- 🗂️ **本地周报存档**：自动保存多个周报版本，可快速创建、复制、切换和删除。
- 🖼️ **一键导出**：支持导出图片、PDF、Word，方便群内同步、正式归档或二次编辑。
- 💾 **纯前端运行**：数据保存在浏览器 `localStorage`，无需登录、无需服务器。
- 🧩 **稳定导出效果**：关键装饰图标采用 base64 内嵌，并针对导出做了样式适配。

## 🚀 快速开始

### 方式一：直接打开

双击打开：

```text
index.html
```

即可在浏览器中使用。

### 方式二：本地静态服务

在项目目录下运行：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 🧩 核心功能

### 多主题切换

顶部工具栏可切换五套视觉风格：

| 主题 | 风格特点 |
|---|---|
| 有机苔原绿 | 温和、自然、适合稳重型汇报 |
| 深邃普鲁士 | 专业、克制、偏商务管理风 |
| 新中式雅致 | 雅致、有文化感、适合正式复盘 |
| 硅谷活力橘 | 明快、科技、适合创新项目汇报 |
| 极智克莱因 | 高对比、现代、适合视觉冲击型汇报 |

### 编辑 / 阅读模式

- **编辑模式**：用于撰写、调整内容、编辑表格和高级组件。
- **阅读模式**：用于预览和导出，隐藏编辑辅助控件，呈现最终报告效果。

### 内容区块编辑

支持正文段落、各级标题、列表、高亮框、提示框、表格和高级组件区块。区块可移动、复制、插入和删除。

### 表格编辑

支持单元格编辑、增删行列、合并 / 拆分单元格、对齐和自动换行，适合放项目进度、风险清单、指标完成度和下周计划。

### 三大高级组件

- **项目甘特图**：展示项目时间线、阶段和任务节奏。
- **项目进度看板**：按待启动、进行中、已完成展示项目状态。
- **日程看板**：直观呈现一周会议、评审、复盘和协作安排。

### 本地周报存档

周报会自动保存到浏览器本地，可保留多个版本。所有数据存储在 `localStorage`，不上传服务器。

> 注意：换电脑、换浏览器、清空缓存或使用隐私模式时，本地存档可能丢失。重要周报建议及时导出备份。

## 📁 项目结构

```text
weekly-review/
├── index.html
├── styles/
│   └── main.css
├── scripts/
│   └── main.js
├── assets/
│   └── icons/
└── foliage.svg
```

核心文件：

- `index.html`：页面结构和第三方导出库引用。
- `styles/main.css`：基础排版、主题样式、组件样式和导出相关样式。
- `scripts/main.js`：主题切换、自动保存、区块编辑、组件渲染和导出逻辑。
- `assets/`：图片素材和图标备份。

## 📦 部署说明

项目是纯前端单页应用，可部署到任何静态网站环境，例如 GitHub Pages、Vercel、Netlify、公司内部静态服务器或 Nginx 静态目录。

最小运行文件：

```text
index.html
styles/main.css
scripts/main.js
```

建议保留完整目录，方便后续替换素材和维护。
