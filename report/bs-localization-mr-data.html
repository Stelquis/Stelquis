一、研究对象概述

维度内容
研究对象存量基站位置推断（BS Localization from MR Data）——已知用户终端的位置和上报的 MR 测量值，反推基站天线的地理经纬度
输入数据MR（Measurement Report）：RSRP（参考信号接收功率）、RSRQ、TA（时间提前量）、AOA（到达角）、邻区 PCI 列表等
输出目标基站（eNodeB/gNodeB）的地理坐标（经度、纬度）
与 UE 定位的区别UE 定位是用已知的基站位置推用户位置；这里是反过来——用已知的 UE 位置（如 GPS 采样点）+ MR 信号测量，反推基站位置
工程意义运营商资产管理系统中的站点工参（经纬度）可能不准确、过期或缺失，通过 MR 数据反演可校验和补全基站位置信息

一句话定义：基站位置推断相当于"逆向定位"——把 UE 定位问题反过来求解：已知大量采样点的信号测量值和 GPS 位置，反推出基站天线在哪。精度受限于多径传播、GPS 误差和 TA 量化分辨率。

二、纵轴：技术演进

基站位置推断的技术发展可以追溯到蜂窝网络诞生之初。随着测量手段的丰富和 ML 技术的成熟，精度从公里级逐步提升到数十米级。

2.1 几何方法时代：Cell-ID / TA / AOA（2000s–2010s）

2000s
Cell-ID：基站位置 ≈ 用户位置
最简单的方法：用户所在的服务小区基站位置直接作为用户位置的近似。精度完全取决于小区覆盖半径——城区 100–500m，郊区 1–5km。
2010s
TA（时间提前量）测距
TA 是基站根据信号传播延迟计算的时间提前量。LTE 中 TA 分辨率 78m/step（550m 步长 × 传播速度折算），5G NR 中提升至约 4.88m/step。将 TA 转化为距离约束后，结合多个采样点可缩小基站位置的不确定性区域。
2010s
AOA 到达角 + 三角定位
利用基站天线阵列估计用户信号的来波方向，多个基站测量同一终端的 AOA 后可形成射线交会定位。精度受天线阵列规模和 NLoS 环境影响。
方法精度优点局限
Cell-ID100m–5km零成本，无需额外数据精度极低，依赖覆盖半径
TA 测距50–300m直接反映距离，4G/5G 标准支持多径导致距离偏大，量化误差
AOA 三角定位20–200m仅需少量基站即可定位需天线阵列，NLoS 下误差极大
ECID（增强 Cell-ID）50–150m结合 TA+RSRP+AOA，兼容性好精度有限，作为其他方法的兜底

2.2 传播模型方法：路径损耗拟合（2010s–2018）

2010s
RSRP → 距离转换 + 圆交会
利用路径损耗模型（Cost231、FSPL、Macro、Walfisch-Ikegami）将 RSRP 测量值转换为基站到终端的距离估计，然后以多个基站为圆心画圆，交会点即为用户位置（或反过来求基站位置）。

核心流程：

MR 数据 → 选取路径损耗模型 → RSRP → 距离估算 → 圆交会 / 插值 → 位置输出
路径损耗模型适用场景特点
FSPL（自由空间）简单 LOS最简单，误差大
Cost231-Hata城区/郊区/农村宏站与蜂窝宏站分类吻合度好
Walfisch-Ikegami城市街谷/峡谷场景复杂传播环境，需参数调优
Macro（3GPP）宏蜂窝标准场景标准推荐，通用性好

⚠️ 关键问题：传播模型是 RSRP→距离转换中最关键也最脆弱的一环。模型参数不准（如天线高度、建筑物密度）会导致距离估算偏差放大。在城区 NLoS 场景下，信号衰减远大于理论值，会显著高估距离。

2.3 指纹定位时代：kNN / 加权质心（2015–2020）

2015–2020
信号指纹匹配定位
离线阶段：在已知位置采集信号指纹（RSRP 向量 + 邻区列表）建立指纹库。在线阶段：将实时测量值与指纹库匹配，用 kNN 算法找出最近邻，加权平均得到位置。UE 定位精度可达城区 30m、农村 105m（中位数）。

指纹反推基站位置：如果指纹库中的采样点带有 GPS 位置标签，且已知每个采样点检测到的基站 PCI 和 RSRP，可以通过加权质心法反推基站位置——将所有测量到该基站的采样点的位置按 RSRP 加权平均。

方法典型误差（城区）典型误差（农村）
加权质心（RSSI 加权）均值 ~215m>500m
动态加权质心（可变 BTS 数）CDF 100m: ~48%CDF 250m: ~98%
kNN 指纹匹配中位数 ~30m中位数 ~105m
多元线性回归（RSSI）67% 误差 <64m最大 275m

2.4 机器学习时代：回归模型 / 随机过程（2018–2022）

2018–2022
多模型对比：线性回归/Bayesian Ridge/Lasso 等
实际路测数据（TA + RSRP + RSRQ + GPS）训练回归模型预测基站距离。8 种机器学习算法对比中，Lasso 和 Ridge 回归表现最佳（MSLE ~0.16）。关键发现：每个基站的环境不同，需要为每个基站独立训练模型。
2022
随机模型：明确分解误差来源
Eller et al. 提出基于 TA 的 BS 定位随机模型，直接建模 GPS 噪声（Rician）、多径传播（指数分布）、TA 量化（确定性）三类误差。无需先验基站候选，均值误差 <100m；有候选集时识别准确率 95%。

2.5 深度学习时代：GNN / Attention / CSI（2022 至今）

2022–2024
GNN / GAT 用于 5G 波束级定位
5G NR 的多波束特性提供了丰富的空间信息。GNN 利用 beam RSRP + LoS/NLoS 标签构建图结构，Graph Attention Network 动态学习邻居节点权重。64 波束下 80% 误差 <7.68m，12 波束下 80% 误差 <15.1m。相比 ToA 三角定位，NLoS 下优势显著。
2024–2025
Attention + 不确定性估计
利用 self-attention 处理信道冲激响应波束矩阵，结合负对数似然或回归分类实现不确定性估计。在商用 5G 基站实测中（3.85GHz，100MHz 带宽），LoS/NLoS 混合场景达到亚米级定位精度。
2025
超图神经网络：解决 MR 缺失位置问题
针对 MR 数据缺少 GPS 位置标签的普遍问题，提出基于超图神经网络的半监督方法，通过距离感知超图建模和超图卷积从多模态信息中提取位置，在真实 MR 数据集上验证了优越性能。

2.6 混合方法时代：随机模型 + 多源融合（当前）

当前主流
"几何 + 传播模型 + ML" 多层融合
实际工程中，单一路径损耗模型不够用。当前最佳实践：先用多种传播模型估算距离（FSPL/Cost231/Macro/WI），加权决策融合；AOA 方向校正；RSRP 偏差大时用比例校正；最终用最小残差/加权质心/最小二乘输出坐标。
2025–2026
同时定位 + 建图（SLAM-like）
Simultaneous LTE Signal Propagation Modelling and BS Positioning：在不知道传播模型参数和基站位置的情况下同时估计两者，利用车载 GPS + RSRP 测量值联合优化路径损耗模型参数和基站坐标。

四、横纵交叉：洞察与推演

4.1 方法演进的内在逻辑

  1. 从"硬几何"到"软概率"：早期方法依赖三角定位等确定几何关系，逐步演进到用概率模型处理多径、量化、GPS 噪声等不确定因素。Eller et al. 的随机模型是这一转变的标志性工作——明确分解三类误差源，让模型"知道自己不知道"。
  2. 数据驱动正在超越模型驱动：GNN 和深度学习方法在 5G 多波束场景下达到亚米级精度，远超传统传播模型方法的 50–200m。但代价是数据需求和计算开销大幅上升，且泛化能力尚未充分验证。
  3. "同时定位与建图"是终极形态：2025–2026 年的 SLAM-like 方法（同时估计传播模型参数和基站位置）代表了基站定位的最高形态——不需要先验传播模型参数，也不需要基站工参，仅靠 MR 数据即可完成全部推断。

4.2 MR 数据质量的核心约束

数据问题描述影响程度应对策略
GPS 缺失大量 MR 数据没有 GPS 位置标签高 半监督学习、超图神经网络、MDT 补充
GPS 误差城区 GPS 误差可达 10–50m中高 建模为 Rician 分布，纳入误差模型
多径传播NLoS 下信号走行距离 > 直线距离高 指数分布建模多径偏量、AOA 方向校正
TA 量化LTE: 78m/step, 5G NR: 4.88m/step中 纳入确定性系统模型、5G 分辨率大幅改善
采样分布不均路测数据集中在道路，覆盖不均匀中 DOP（精度因子）评估几何分布优劣

4.3 未来推演

短期（1–2 年）

  • TA + 随机模型成为工程标准：仅需 TA 和 GPS 两个参数，无需传播模型调参，均值误差 <100m，适合大规模部署
  • 5G NR TA 高分辨率红利释放：4.88m 的 TA 分辨率使基站位置推断精度大幅提升，LTE 时代的量化误差不再是瓶颈

中期（3–5 年）

  • GNN + 波束 RSRP 成为高精度方案基线：在 5G Massive MIMO 普及后，beam-level 的空间信息将支撑 10m 级基站定位
  • MR + MDT 数据融合：MDT（Minimization of Drive Testing）提供更丰富的带 GPS 标签的测量数据，弥补纯 MR 数据的位置缺失

长期（5 年以上）

  • 联邦学习 + 分布式基站定位：各省份 MR 数据不出域，联合训练基站定位模型
  • 数字孪生驱动的基站自校准：基站位置偏差由系统自动检测并修正，无需人工巡检
