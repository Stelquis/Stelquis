一、研究对象概述

维度内容
研究对象大模型持续学习（Continual Learning for LLMs）——让大语言模型在部署后持续吸收新知识、新任务、新场景，而不遗忘已学能力的技术体系
技术范围LoRA 专家系统（MoLoRA）→ 双层路由 MoE（BR-MoE）→ 快慢分层训练（FST）→ 自蒸馏（SDFT / SDPO / OPSD）→ 在线记忆机制（δ-mem）→ 基础设施（MinT）
核心问题大模型能否像人类一样"边用边学"——在部署后不中断服务、不遗忘旧知识的前提下，持续迭代能力？现有技术路线如何选择、如何落地？
行业背景2026 年被业界视为"持续学习元年"——从 Ilya Sutskever 到各大 AI Lab 形成共识：下一代"超级智能"应当是持续学习器，而非冻结的成品模型

一句话定义：持续学习要回答的核心命题是：当模型学会新任务时，如何不忘记已经会做的事、不退化学习新东西的能力、同时不破产（算力可控）——这是大模型从"成品"走向"生命体"的关键一跃。

2.1 Macaron-V1：LoRA 专家驱动的持续学习框架

🏭 提出方：Mind Lab（Mindverse，中国团队）
基于冻结的万亿参数基础模型（GLM-5.2 / Qwen3），通过 MoLoRA 实现能力持续扩展

核心理念：在冻结的万亿参数基础模型上，通过 LoRA（低秩适配）专家模块持续学习新经验，而非全量重训。每个 LoRA 专家负责一类能力，通过强化学习（RL）动态调整参数。

架构设计

  • Mixture-of-LoRA（MoLoRA）：挂载多个 LoRA 专家（L0–L3），分别负责对话、Agent 任务、代码生成、UI 操作
  • RL 驱动：模型执行任务 → 评估结果 → 动态调整 LoRA 参数，实现"经验持续内化"
  • 插件化扩展：新能力通过 LoRA 模块动态添加，不破坏原有知识

核心优势

维度传统全量微调Macaron-V1
训练成本全量训练 ≈ 100% 算力LoRA RL 训练 ≈ 10% 算力
扩展方式重新训练整个模型动态挂载新 LoRA 专家
知识隔离新旧知识耦合专家模块天然隔离
实际效果—一句提示词即可生成复杂 3D 巧克力工厂

2.2 CaRE：首个支持 300+ 任务的持续学习架构

🏫 提出方：香港大学团队
提出双层路由混合专家（BR-MoE），支持超长任务序列持续学习

核心创新：提出双层路由混合专家（BR-MoE, Bi-level Routing Mixture-of-Experts）架构，同时满足"判别性"和"全面性"双重目标。

  • 第一层（动态路由）：根据输入语义自动筛选最相关的任务群
  • 第二层（专家融合）：从相关任务中提取互补专家知识，动态融合

支撑数据

  • 构建 OmniBenchmark-1K 基准数据集，支持超长任务序列（300+ 任务），填补业界空白
  • 在 300+ 任务序列中，性能显著优于现有方法，证明长序列持续学习的可行性

💡 工程启示：当电信客服意图体系包含数百个细粒度意图时，CaRE 的双层路由机制可自动将"套餐资费投诉"路由到计费专家群，将"信号故障报修"路由到网络专家群——无需人工编排。

2.3 FST 框架：快慢分层训练，破解灾难性遗忘

🏢 提出方：Databricks + 伯克利（Matei Zaharia, Joseph Gonzalez 等）
借鉴大脑"快-慢权重"分工，通过分层训练避免灾难性遗忘

核心理念：大脑并非用一个速率更新所有知识——有些连接快速适应新情境（快权重），有些则稳定承载长期记忆（慢权重）。FST 将这一机制引入 LLM 训练。

权重类型角色更新策略
⚡ 快权重（Fast）快速适应当前任务（如 CodeIO 代码题）仅在训练中短期更新，高学习率
🐢 慢权重（Slow）承载长期通用能力（如推理能力）通过 RL 缓慢更新，低学习率

效果数据

  • 在 CodeIO 任务上，训练步数减少 3 倍，遗忘率降低 70%
  • 同一模型连续学习三类任务（HoVer、CodeIO、Physics）时，性能显著优于传统 RL
  • 通过 GEPA 优化器动态平衡快慢权重

🔑 关键洞察：FST 的核心贡献在于证明了"快慢分离"在 LLM 训练中有效——这为持续学习中的"可塑性-稳定性困境"提供了工程上可操作的解决方案，而不仅仅是理论构想。

2.4 Self-Distillation：自蒸馏驱动内生增长

🎓 提出方：MIT × ETH Zurich × Meta × Stanford 等联合
无需外部强教师，通过"自省+对比"实现策略内对齐

核心理念：传统蒸馏依赖强教师模型（如 GPT-4），成本高且受限于教师能力。自蒸馏系列工作让模型利用自身生成的信息作为监督信号，实现闭环进化。

方法全称核心机制适用场景
SDFT自蒸馏微调用少量专家演示诱导教师分布，模型自蒸馏拟合该分布指令微调、领域适配
SDPO自蒸馏策略优化将环境反馈（如报错信息）转化为 Token 级监督信号代码生成、工具调用
OPSD策略内自蒸馏构建"教师-学生"策略内对齐，最小化分布 KL 散度长程推理、数学证明

核心优势

  • 学习效率提升 4–8 倍（在 MATH、GSM8K 等复杂推理任务上）
  • 无需强教师：通过模型自身生成的上下文反馈实现闭环升级
  • 打破 RL 局限：在长程推理任务中有效解决"信用分配"问题

2.5 δ-mem 与 MinT：记忆机制与基础设施

δ-mem：LoRA 内嵌的在线记忆机制

🧠 提出方：Mind Lab
为 LoRA 设计的在线记忆机制——在 8×8 矩阵中存储动态记忆

MinT：面向百万 LoRA 的基础设施系统

🏗️ 提出方：Mind Lab

  • 支持 LoRA 策略的训练、部署、回滚
  • 通过"打包 MoE LoRA 张量"和"二阶段 rollout"降低冷启动延迟 8.5 倍

💡 工程启示：MinT 的百万级 LoRA 管理能力，意味着一个电信运营商可以在一个基座模型上维护"每个地市 + 每个业务线"的专属 LoRA adapter——省级公司维护通用客服能力，地市级公司维护本地化话术。

4.1 三大核心挑战

持续学习之所以困难，是因为大模型在持续学习过程中面临三个根本性矛盾，被称为"持续学习的三座大山"：

#挑战英文术语现象描述被哪些技术攻克
1 灾难性遗忘 Catastrophic Forgetting 学习新任务时，模型对旧任务的性能断崖式下降。例如：学会识别"5G 套餐办理"后，忘记"宽带续费"的处理策略 FST 慢权重 LoRA 模块隔离 自蒸馏保留
2 可塑性退化 Plasticity Degradation 模型学得越多，学习新东西越困难——参数空间逐渐"固化"，对新数据的敏感度下降 FST 快权重 δ-mem 增量
3 算力成本高 Computational Cost 全量重训在万亿参数模型上不可行——单次全量微调成本可达百万美元级别 LoRA 低成本 自蒸馏 4-8x MinT 高效部署
